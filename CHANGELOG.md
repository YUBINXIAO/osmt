## [0.1.0] - 2026-10-21

### Added

- Initial release of the Open Source Maintainer Toolkit.
- `osmt triage` – priority-sorted list of open issues and PRs.
- `osmt stale` – detect inactive items.
- `osmt release-notes` – draft release notes from conventional and free-form commits.
- `osmt health` – quick repository health snapshot.
- Public GitHub API support (token optional for higher rate limits).
- Basic unit tests and GitHub Actions CI.
- Issue and pull request templates.
